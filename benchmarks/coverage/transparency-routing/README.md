# Finite transparency decision integration

Run commands and exact boundaries are documented in `references/coverage/transparency-routing.md`. Fresh full-suite collectors are executed before choosing from their source/input/budget-bound evidence; this is a diagnostic adapter, not on-demand production rendering. Both software backends choose validated sorting or peeling for supported requests and explicitly reject overflow, ties and unmet quality. Weighted-OIT evidence is audited but never falsely relabeled as the same geometry.
