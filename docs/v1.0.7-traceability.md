## Runtime scenario mapping

S01 versions/extensions; S02 driver-binary invalidation/fallback; S03 material
offset/sampler bindings; S04 bloom graph; S05 compute-buffer draw; S06 MSAA resolve;
S07 premultiplied glass/particles; S08 sRGB/HDR transfer (C03 adds HDR); S09 actual
two-material switching and reflected ABI mismatch; S10 startup timing categories.
Undefined barrier/feedback cases are rejected before unsafe GL consumption.
Correct pixels from an undefined draw would not constitute proof of correctness.

The version matrix restricts a single Mesa implementation to 3.0/3.1/3.2; it is
not three independent hardware devices. CPU analytic images are independent
equations, not screenshots captured from the renderer being tested. Host shader
wall time is not GPU time or guaranteed cold-driver compilation.

## Evidence and reproduction

Tracked [evidence](v1.0.7/evidence/) includes command results, compiler logs,
runtime/source/reference hashes and actual image outputs. The aggregate local
check report lists commands with their exit codes and log hashes. It distinguishes
unit/schema checks, actual software EGL, authored fault controls, and deliberately
blocked full release. Re-run commands from [the lab guide](../benchmarks/pipeline/README.md)
with C++17, EGL/GLES headers, glslang and jsonschema installed.

Independent review identified and corrected uniform-location false ABI mismatch,
malformed member types, cache stage-source/backend/ABI identity, bounded binaries,
strict graph flags, unresolved multisample reads, imported-resource reuse and
timeout/error reporting. Final independent review also corrected reflected member
type/extent/orientation checks, missing sampler reflection, legal varying precision
differences, named-resource ordering and persistent consumer visibility after
cross-context synchronization. Additional review and final command receipts are recorded
in the final evidence ledger; no GitHub approval was self-issued.

## Delivery policy

Merge of the tested candidate is distinct from publication of a release. Do not
change `metadata.version`, tags, prior gate files or permissions to make the
candidate appear accepted. `--require-release` intentionally exits2. Manual CI
configuration is updated, but remote execution is not authorized by this document.
