Infrastructure tests are separate from actual shader/host execution, and both are
separate from physical GPU/device, CI and live-model tests. The current SDK/compiler
paths are environment-specific; they do not imply a bundled target toolchain.
`docs/v1.0.4/evidence/` stores current and explicitly named baseline records. The first
DeviceLab attempt failed strict compilation because an included renamed main lacked
an explicit return; its error is retained, the existing main now returns 0 explicitly,
and corrected/final runs are separately recorded. The initial `repair-reproduction.json` is a superseded replay-backed development record; final acceptance uses `repair-reproduction-fresh.json`, which freshly executes all 24 controls.

## Review corrections

- S07's deliberate indirect-buffer mutation now uses BUFFER_UPDATE_BARRIER_BIT before API-side overwrite of compute-written storage; software success alone would not expose this portability race.
- Wallpaper surface destruction waits for its render owner to cancel frame callbacks and release the surface, including owner-exit and interruption handling; static contract tests are not Android runtime proof.
- Repair reproduction now freshly builds/runs scenes and checks source/runner/binary/image identity, rather than trusting historical JSON verdicts.
