## Manual incremental operation

```sh
python references/research/update_radar.py --start 2026-10-02 --end 2026-11-01 --archive reports/radar
# Optional --decisions reviewed-decisions.json validates candidate/source_verified/
# reproduced/accepted/rejected/deferred transitions and required evidence mappings.
```

Run weekly with explicit UTC closed-date boundaries; preserve source failures and date-unknown rows. Monthly review maps accepted signals to rule IDs, device conditions, minimal sample, test IDs and affected sections. An accepted row additionally needs reviewer/reproduction evidence. Static pages and vendor/X sources require manual review; they are never represented as an automatic successful fetch. The CLI archives validated decision rows but does not apply patches or install schedules.
