# Typed finite runtime evidence links

`python3 tools/coverage/runtime_links.py` validates the closed `runtime-links.json` contract offline. Tests: `python3 -m unittest discover -s tools/coverage -p test_runtime_links.py -v`.

Eight receipts select four probes × two software drivers; six distinct API names, not six fully covered API specifications. Existing 24 C++ semantic-link rows remain separate and unchanged. No arbitrary JSON assertion expressions, caller-selected expected values, commands or imports are executed. The validator owns fixed assertion paths, required case identities, polarity/error codes, route and pixel/canary invariants. Row fields/schema are exact; boolean/integer assertions are type-sensitive. Core versions and extension require blocks must match the frozen registry catalog. Missing receipts, unknown routes, mismatched hashes, path escape, changed expected and actual errors, policy-as-actual substitutions and unsupported reports fail INCOMPLETE.

Each row binds collector SHA and exact report SHA, and the report must bind the same collector source. Only HOST_PASS SOFTWARE_HOST results count. Debug: synchronous insertion plus actual invalid-source error. Timer: available before elapsed result access plus actual active-query access error. Robust: normal tight read plus actual undersized-buffer rejection/canary. External: exact RGBA sampling plus actual invalid mipmap filter. These are finite boundary links; notably the external negative links glTexParameteri, not all EGLImage functions. Every selected negative is an actual API error; timer injected disjoint, fallback policy controls and CPU oracle mutation tests do not count as GPU negatives.

Hashes provide drift/integrity checks, not trustworthy third-party authentication against an attacker rewriting both source and receipts. No re-execution is performed by this validator. Underlying experiments and their independent reviewers remain the semantic evidence boundary. Registry indexing is not runtime acceptance. Unlinked APIs remain UNKNOWN, compiled is NOT_EVALUATED, device/provider remain NOT_RUN, release_ready stays false. No hardware performance, full driver certification or unsupported capability becomes PASS. Upstream source/catalog integrity is delegated to the existing fixed-registry checker; this validator does not fetch head.

Observed route/version/advertised prerequisites are verified for debug and robustness; external prerequisites and actual CPU RGBA bytes are checked. Robust normal payload and both canaries are independently reconstructed, not compared to caller expected_payload. Debug callback text/type/severity/source sequence has a fixed golden. Timer report stores only pixel_match rather than raw pixels, so its workload correctness is collector-attested, not independently re-derived by this link checker; timing validity/performance is not the linked boundary. The timer receipt lacks queried API version, so registry version is legal minimum routing metadata, not a newly measured version.
